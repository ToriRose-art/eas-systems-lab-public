# AI Application Clarity Standard

**Draft 1 · Open-core concept**

A small, reusable standard for organizations to state whether AI-assisted applications are welcome, limited, disclosure-based, or prohibited.

## Why it exists

Applicants should not have to guess whether using AI for accessibility, translation, organization, drafting, or speed is acceptable. Organizations should be able to state their position clearly without building a new compliance system.

## This standard is

- A plain-language policy statement
- An optional machine-readable JSON record
- An optional applicant attestation pack
- A reusable public template

## This standard is not

- Identity verification
- A scam-prevention system
- A security certification
- An AI detector
- Proof that an applicant or organization is legitimate
